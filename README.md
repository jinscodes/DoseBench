# DoseBench website

Astro + TypeScript starter for the DoseBench research project page.

## Local development

```sh
npm install
npm run dev
```

Open `http://localhost:4321`.

## Checks and production build

```sh
npm run check
npm run build
npm run preview
```

The production output is written to `dist/`.

## Content to replace

- Update the paper and code links in `src/pages/index.astro`.
- Replace the hero copy with the one-sentence DoseBench contribution.
- Add paper figures to `public/images/` and replace the figure placeholder.
- Add the author and institution information in the footer.

The GitHub Pages base path is configured for the `DoseBench` repository in
`astro.config.mjs`. Change it if the site moves to a dedicated repository.
